# Excel Day 1 — Basics

## Topics Covered

- Excel basics
- Workbook and worksheet
- Rows and columns
- Cells
- Formatting
- Relative references
- Absolute references
- Mixed references

## Key Learning

- Workbook = Excel file
- Worksheet = Sheet inside workbook
- Row = Horizontal
- Column = Vertical
- Cell = Column + Row
- A1 = Relative reference
- $A$1 = Absolute reference
- $A1 = Column fixed
- A$1 = Row fixed

### Relative vs Absolute Reference

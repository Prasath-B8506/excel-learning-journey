## Key Learning

Sort → Arranges data

Filter → Shows selected rows

Excel Table → Converts a data range into a structured table

Data Validation → Controls data entry

Conditional Formatting → Highlights data based on conditions

## Important Differences

Sort changes the order of the data, while Filter shows only matching rows.

Data Validation controls what can be entered, while Conditional Formatting changes how matching data looks.

## Interview Questions

### What is the difference between Sort and Filter?

Sort changes the order of the data, while Filter displays only the rows that meet selected conditions.

### What is Data Validation?

Data Validation controls the type of data or values that can be entered into a cell.

### What is Conditional Formatting?

Conditional Formatting automatically changes the appearance of cells based on specified conditions.

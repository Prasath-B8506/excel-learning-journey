## Key Concepts

### Workbook
An Excel file that can contain one or more worksheets.

### Worksheet
An individual sheet inside an Excel workbook.

### Row
A horizontal set of cells identified by numbers.

Example: 1, 2, 3, 4

### Column
A vertical set of cells identified by letters.

Example: A, B, C, D

### Cell
The intersection of a row and a column.

Example:

`B3`

means Column B and Row 3.

### Formatting
Formatting changes the appearance of data without changing the underlying value.

Examples:

- Bold
- Number format
- Currency
- Alignment
- Borders

---

## Cell References

### Relative Reference

Example:

`A1`

A relative reference changes when a formula is copied.

### Absolute Reference

Example:

`$A$1`

An absolute reference stays fixed when a formula is copied.

### Mixed Reference

Examples:

`$A1` → Column fixed

`A$1` → Row fixed

## Interview Questions

### What is the difference between a workbook and worksheet?

A workbook is the Excel file, while a worksheet is an individual sheet inside the workbook.

### What is the difference between a row and a column?

A row is horizontal and identified by numbers, while a column is vertical and identified by letters.

### What is the difference between relative and absolute references?

A relative reference changes when copied, while an absolute reference stays fixed.
